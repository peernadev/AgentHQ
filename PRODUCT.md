# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Hackathon teammates coordinating human and AI coding work across laptops; reviewers viewing the dashboard on a projector. Mobile access must work at 375px.

## Product Purpose
Make it immediately clear what needs attention and what to do next. Preserve mission planning, file-scoped tasks, workers, draft approval, queue order, review evidence, fairness, and event history.

## Positioning
A shared mission-control workspace connecting team goals to scoped parallel work and reviewable results. Google-native integration follows SPEC.md.

## Operating Context
Next.js web application, Firebase and Gemini team backend, Git worktrees, pull requests, and human merge. This UI phase uses clearly identified local mocks until the next backend handoff.

## Brand Commitments
Keep AgentHQ. On 2026-11-21 the user rejected the first generic dashboard and requested an original, premium, aesthetic, consistent identity with clear copy and custom logo/icons. Apple imitation was explicitly rejected. Attention and next actions are the confirmed information priority.

## Capabilities and Constraints
Preserve shared API contracts and backend ownership. Existing typed fixtures and functional mock interactions are evidence, not live service behavior. Never ship credentials or imply mock reviews are real AI calls.

## Product Principles
- Surface decisions before activity.
- Make each action and its consequence understandable.
- Give every state a consistent visual and verbal meaning.
- Maintain readable density for teams and projector demonstrations.
